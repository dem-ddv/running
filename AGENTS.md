# Длинная дистанция

Публичные страницы в этом репозитории собираются из явно разрешённых полей.
Храни исходные данные вне репозитория. Все файлы и история публичного
репозитория доступны читателям.

Для оценочного марафонского темпа сборка вычисляет `records.is_quality`
из исходных `content` и `comment`. В экспорт каждой тренировки входят
только дата, дистанция и этот булев признак. Исходные комментарии к
тренировкам нельзя переносить в HTML, другие наборы данных, PR, диффы,
логи, чаты и резервные копии. Авторские «Заметки» и подписи к длинным
пробежкам являются редакционным контентом.

Собери обе страницы командой
`node scripts/public-data.mjs build /path/outside/repo/private-data.json`.
Входной JSON содержит наборы данных дашборда и исходные поля тренировок.
После добавления файлов в индекс запусти `node scripts/public-data.mjs check`
перед публикацией. Эту же проверку запускает GitHub Actions.
Расширяй список разрешённых полей и файлов только при явном решении
опубликовать новые данные. После деплоя проверь HTML обеих публичных
страниц на ddvpage.ru.
